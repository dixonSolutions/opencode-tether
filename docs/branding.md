# Branding

opencode-tether is an **unofficial, independent hobby project**. It is not affiliated with, endorsed by, or sponsored by the opencode project or its maintainers.

## The mark

The icon uses the opencode box mark to identify the service this app connects to, plus a small orange tether link. The mark is not a claim of official status. If the opencode project asks the project to change its icon or name, that request should be respected.

Source files:

- `branding/icon.svg` — master square icon
- `branding/wordmark.svg` — wordmark
- `branding/icon-1024.png` — raster master used for Tauri/Android/Flatpak/PWA icons
- `branding/favicon.ico`

The app does not use the default Svelte or Tauri icons. The web favicon, PWA icons, Android launcher icons, Tauri bundle icons, and Flatpak icon all come from `branding/icon.svg`.

## Colors

- Background: near-black `#0b0a0a`
- Surface: `#171313`
- Official-box white: `#ffffff`
- Inner box: `#5A5858`
- Tether accent: `#fab283` (used for the link, the primary action, focus rings, and live indicators)

## Name

`opencode-tether` is written lower-case in prose, as a product name and package name. The app is sometimes shortened to **tether** in the UI. "opencode" is the separate upstream project.

## Tone

The UI should say "unofficial" once, clearly, on first run and in About. It should not be repeated on every screen. The app should feel like a focused tool, not an official client.
